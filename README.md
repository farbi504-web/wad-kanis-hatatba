# واد كنيس حطاطبة — منصة الإعلانات المبوّبة

منصة إعلانات مبوّبة عربية (RTL) لمدينة حطاطبة وولاية تيبازة والمناطق المجاورة في الجزائر.

## ✨ المزايا

### للمستخدمين
- تصفّح الإعلانات حسب الفئة أو المدينة مع بحث وفلترة
- نشر إعلانات مع صور (ضغط تلقائي)
- محادثات مباشرة بين البائع والمشتري
- قائمة مفضّلة وتقييمات للبائعين
- إشعارات وبلاغات عن الإعلانات المخالفة

### للمدير
- لوحة تحكم شاملة بإحصاءات
- مراجعة الإعلانات والموافقة عليها
- إدارة المستخدمين والفئات والمدن
- بانرات ورعاة وإعلانات مميّزة
- سجل نشاط وتصدير البيانات

### الأمان
- كلمات المرور مُجزّأة بـ bcrypt
- **أرقام الهواتف مشفّرة** بـ AES-256-GCM
- مصادقة ثنائية (2FA) اختيارية
- جلسات JWT بكوكيز آمنة (HttpOnly + Secure)
- حماية من القوة الغاشمة (10 محاولات/15 دقيقة)
- فحص الصور بالمحتوى الفعلي لا بالامتداد
- رأسيات أمان كاملة (HSTS، X-Frame-Options، CSP)

## 🚀 التشغيل محلياً

### المتطلبات
- Node.js 20+
- PostgreSQL 14+

### الخطوات

```bash
# 1. تثبيت الحزم
npm ci

# 2. إعداد المتغيرات
cp .env.production.example .env
# افتح .env واضبط DATABASE_URL والمفاتيح السرية

# 3. توليد المفاتيح السرية
bash scripts/generate-secrets.sh

# 4. إنشاء الجداول
npx drizzle-kit push

# 5. التشغيل
npm run dev
```

افتح [http://localhost:3000](http://localhost:3000)

### تهيئة البيانات الأساسية

تُنشئ 8 مدن و12 فئة وحساب المدير:

```bash
curl -X POST http://localhost:3000/api/seed \
  -H "x-seed-secret: قيمة_SEED_SECRET"
```

> يتطلب ضبط `ADMIN_PASSWORD` (12 حرفاً فأكثر) في `.env`.

## ⚙️ متغيرات البيئة

| المتغير | إلزامي | الوصف |
|---------|:------:|-------|
| `DATABASE_URL` | ✅ | رابط PostgreSQL |
| `DATABASE_SSL` | ⚠️ | `true` مع أي قاعدة سحابية (Neon/Supabase) |
| `AUTH_SECRET` | ✅ | مفتاح توقيع الجلسات |
| `ENCRYPTION_KEY` | ✅ | تشفير أرقام الهواتف (32 bytes hex) |
| `ENCRYPTION_SALT` | ✅ | ملح التشفير |
| `SEED_SECRET` | ✅ | حماية مسار التهيئة |
| `ADMIN_EMAIL` | ✅ | بريد المدير |
| `ADMIN_PASSWORD` | ✅ | كلمة مرور المدير (12+ حرفاً) |
| `FORCE_SECURE_COOKIE` | ⚠️ | `1` في الإنتاج (HTTPS) |
| `BLOB_READ_WRITE_TOKEN` | ⚠️ | إلزامي على Vercel لتخزين الصور |

راجع `.env.production.example` للقائمة الكاملة.

> 🔴 **تنبيه:** مكتبة `pg` لا تقرأ `sslmode` من رابط الاتصال. لا بد من
> `DATABASE_SSL=true` صراحةً مع القواعد السحابية وإلا فشل الاتصال.

| **VPS / Railway** | [`DEPLOYMENT.md`](./DEPLOYMENT.md) | سكربتات Nginx و systemd جاهزة في `scripts/` |

### تخزين الصور

الكود يتكيّف تلقائياً:

- **بوجود `BLOB_READ_WRITE_TOKEN`** → Vercel Blob (تخزين دائم)
- **بدونه** → القرص المحلي `public/uploads` (تطوير أو VPS بقرص دائم)

> ⚠️ على Vercel نظام الملفات مؤقت — بدون Blob تختفي كل الصور المرفوعة.

## 📝 ملاحظات مهمة

### الإعلانات تحتاج موافقة

الإعلانات الجديدة تُنشأ بحالة **قيد المراجعة** ولا تظهر للعامة حتى يوافق عليها المدير — حماية من المحتوى المسيء.

**للتعطيل:** لوحة التحكم ← الإعدادات ← `auto_approve_listings`

### الخطوط

المشروع يستخدم خطي **Cairo** و **Tajawal** من Google Fonts. البناء يتطلب اتصالاً بـ `fonts.googleapis.com` — إن كنت خلف جدار ناري يحجبها، حمّل الخطوط محلياً عبر `next/font/local`.

### التهيئة آمنة التكرار

تستطيع تشغيل `/api/seed` أكثر من مرة دون تكرار المدن أو الفئات.
